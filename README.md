# nobitex-executor

⚠️ **تغییر مهم نسبت به نسخه‌ی قبلی:** نوبیتکس اعلام کرده «درخواست‌ها باید از
IP ایران ارسال شوند». چون سرورهای GitHub Actions در ایران نیستند، این پروژه
دیگر روی GitHub Actions اجرا نمی‌شود — به‌جایش روی همان کامپیوتر ویندوزی
خودتان (که در ایران است) اجرا می‌شود. GitHub فقط برای نگهداری نسخه‌ی کد
مفید است، نه اجرا.

اگر قبلاً workflow را در تب Actions ریپازیتوری فعال کرده بودید، همان‌جا
غیرفعالش کنید (Actions → روی workflow کلیک کنید → منوی سه‌نقطه → Disable
workflow) تا اجراهای بی‌فایده و شکست‌خورده نداشته باشید.

## ریسک قطعی برق/اینترنت - مهم

شما گفتید گاهی برق برای حدود ۲ ساعت قطع می‌شود. در همان بازه:
- هیچ سفارش جدیدی باز نمی‌شود و هیچ استاپ/تارگتی روی نوبیتکس اجرا نمی‌شود.
- وقتی کامپیوتر دوباره روشن شد، پیام‌های آن بازه (چون تلگرام آن‌ها را تا
  حدود ۲۴ ساعت نگه می‌دارد) خوانده و پردازش می‌شوند - ولی با تاخیر، یعنی
  قیمت بستن ممکن است با چیزی که ربات سیگنال فرض کرده بود فرق داشته باشد.
- اگر خاموشی از ۲ ساعت خیلی بیشتر شود (نزدیک به ۲۴ ساعت)، امکان از دست
  رفتن دائمی برخی پیام‌ها وجود دارد - این محدودیت خودِ تلگرام است.
- در هر بار روشن شدن، برنامه خودش وضعیت پوزیشن‌های باز را با نوبیتکس چک
  می‌کند (بخش «آشتی‌دهی») و اگر تناقضی دید به شما در تلگرام هشدار می‌دهد.

این ریسک را با تنظیمات زیر کم می‌کنیم، ولی کامل حذفش نمی‌کنیم (چون منشا آن
قطعی برق خانه است، نه یک باگ نرم‌افزاری).

## ۰) پیش‌نیاز روی ویندوز

1. اگر پایتون ندارید: از python.org نسخه‌ی ۳.۱۱ یا بالاتر را نصب کنید. **در
   صفحه‌ی اول نصب، حتماً تیک «Add python.exe to PATH» را بزنید.**
2. تنظیمات روشن‌ماندن ویندوز: Settings → System → Power & sleep → گزینه‌ی
   "Sleep" را روی **Never** بگذارید (هم حالت وصل به برق، هم باتری اگر لپ‌تاپ
   است) - وگرنه ویندوز خودش برنامه را متوقف می‌کند حتی بدون قطعی برق.
3. ورود خودکار بعد از روشن شدن (اختیاری ولی خیلی مهم): اگر ویندوزتان با
   رمز عبور بالا می‌آید، بعد از قطعی برق کسی باید دستی لاگین کند تا برنامه
   دوباره اجرا شود. برای رفع این مشکل:
   - کلید Win+R را بزنید، `netplwiz` را تایپ و Enter کنید
   - تیک «Users must enter a password to use this computer» را بردارید
   - رمز عبور ویندوزتان را وارد کنید و تایید کنید
   - ⚠️ این یعنی هر کسی که فیزیکی به این کامپیوتر دسترسی داشته باشد بدون
     رمز وارد می‌شود - فقط اگر کامپیوتر جای امنی است این کار را بکنید.

## ۱) فایل‌های پروژه را در یک پوشه بگذارید

مثلاً در `C:\nobitex-executor`. تمام فایل‌های زیپ (`executor.py`,
`nobitex_client.py`, `signal_parser.py`, `state_store.py`,
`requirements.txt`, `run_watchdog.bat`, `.env.example`) را همان‌جا کپی
کنید.

## ۲) نصب کتابخانه‌های لازم

Command Prompt (یا PowerShell) را در همان پوشه باز کنید (در File Explorer
داخل پوشه Shift+راست‌کلیک → «Open PowerShell window here») و بزنید:

```
pip install -r requirements.txt
```

## ۳) ساخت فایل تنظیمات .env

فایل `.env.example` را کپی کنید و نامش را به `.env` تغییر دهید (دقت کنید
ویندوز پسوند `.txt` اضافه نکند - در File Explorer اگر پسوندها مخفی است،
از «View → File name extensions» فعالش کنید). آن را با Notepad باز کنید و
مقادیر واقعی خودتان را جایگزین کنید:

- `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHANNEL_ID`, `TELEGRAM_ADMIN_CHAT_ID` -
  همان‌طور که قبلاً از BotFather/‌getidsbot/userinfobot گرفتید
- `NOBITEX_PUBLIC_KEY`, `NOBITEX_PRIVATE_KEY` - از کلید API نوبیتکس
- `NOBITEX_BASE_URL` - برای شروع همان `https://testnetapiv2.nobitex.ir`
  بماند
- `RISK_MARGIN_USDT=1` و `LEVERAGE=10`

## ۴) یک تست دستی قبل از خودکارسازی

قبل از تنظیم اجرای خودکار، یک‌بار دستی امتحان کنید تا خطاها را همین‌جا
ببینید:

```
python executor.py
```

باید خط‌هایی شبیه «شروع اجرا...» و «آشتی‌دهی اولیه تمام شد» ببینید. با
Ctrl+C متوقفش کنید.

## ۵) اجرای خودکار و مقاوم در برابر کرش (`run_watchdog.bat`)

روی فایل `run_watchdog.bat` دوبار کلیک کنید. یک پنجره‌ی سیاه باز می‌ماند و
لاگ‌ها را نشان می‌دهد. **این پنجره را نبندید** - اگر `executor.py` به هر
دلیلی کرش کند، همین فایل بعد از ۱۰ ثانیه دوباره اجرایش می‌کند.

## ۶) اجرای خودکار بعد از هر بار روشن شدن ویندوز (Task Scheduler)

برای اینکه بعد از قطعی برق و روشن شدن دوباره‌ی ویندوز، این کار خودش شروع
شود، بدون این‌که شما دستی روی فایل کلیک کنید:

1. دکمه‌ی استارت ویندوز → تایپ کنید «Task Scheduler» → بازش کنید
2. سمت راست: «Create Task…» (نه Create Basic Task)
3. تب **General**: یک نام بدهید (مثلاً `NobitexExecutor`). گزینه‌ی
   «Run whether user is logged on or not» را بزنید. تیک «Run with highest
   privileges» را هم بزنید.
4. تب **Triggers** → New → «Begin the task» را روی **At startup** بگذارید
   → OK
5. تب **Actions** → New → «Action: Start a program» → در Program/script
   مسیر کامل `run_watchdog.bat` را بدهید (مثلاً
   `C:\nobitex-executor\run_watchdog.bat`) → در «Start in» هم مسیر پوشه
   را بدهید (`C:\nobitex-executor`) → OK
6. تب **Conditions**: تیک «Start the task only if the computer is on AC
   power» را **بردارید** (چون می‌خواهیم حتی با باتری هم اگر لپ‌تاپ است
   کار کند)
7. OK را بزنید - ویندوز رمز عبور اکانتتان را می‌پرسد (برای اجرا حتی بدون
   لاگین لازم است)

بعد از این مرحله، حتی اگر برق قطع و بعد از ۲ ساعت وصل شود، به‌محض روشن شدن
ویندوز (و لاگین خودکار طبق مرحله‌ی ۰.۳)، این کار خودش دوباره اجرا می‌شود.

## ۷) چک کردن که واقعاً کار می‌کند

- فایل `executor.log` در همان پوشه ساخته می‌شود - همیشه آخرین لاگ‌ها آنجا
  هستند، حتی اگر پنجره‌ی سیاه را نبینید.
- یک ری‌استارت واقعی از کامپیوتر بزنید و ببینید بعد از بالا آمدن ویندوز،
  خودش دوباره شروع به کار می‌کند یا نه (بدون این‌که شما دستی کاری بکنید).

## ۸) رفتن روی حساب واقعی

فقط بعد از چند روز تست کامل بدون مشکل روی تست‌نت: مقادیر
`NOBITEX_PUBLIC_KEY` و `NOBITEX_PRIVATE_KEY` را در فایل `.env` با کلید
واقعی جایگزین کنید، `NOBITEX_BASE_URL` را به `https://apiv2.nobitex.ir`
تغییر دهید، و `run_watchdog.bat` را یک‌بار ببندید و دوباره باز کنید (یا
کامپیوتر را ری‌استارت کنید) تا تنظیمات تازه لود شوند. با مبلغ خیلی کوچک
شروع کنید.

## ساختار فایل‌ها

- `nobitex_client.py` — امضای Ed25519 و فراخوانی API نوبیتکس
- `signal_parser.py` — تشخیص نوع پیام کانال از روی متن آن
- `state_store.py` — ذخیره‌ی وضعیت در `state.json`
- `executor.py` — حلقه‌ی اصلی + آشتی‌دهی هنگام روشن شدن
- `run_watchdog.bat` — اجرای مقاوم در برابر کرش، روی ویندوز
- `.env.example` — الگوی تنظیمات (کپی کنید به `.env`)
