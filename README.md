# nobitex-executor

پروژه‌ی سوم و کاملاً مستقل: کانال تلگرام مشترکِ دو ربات سیگنال شما را می‌خواند
و بر اساس متن پیام‌ها (ورود، تارگت، استاپ، بریک‌ایون، بستن اجباری) به‌صورت
خودکار روی نوبیتکس (معاملات تعهدی) سفارش باز/بسته می‌کند.

هیچ فایل، توکن یا ریپازیتوری مشترکی با دو ربات دیگر ندارد.

## ۰) قبل از هر چیز

- این پروژه با پول واقعی و اهرم معامله می‌کند. حتماً اول روی **testnet** تست
  کنید (پیش‌فرض همین تنظیمات).
- این راهنما توضیح فنی است، نه توصیه‌ی مالی.

## ۱) ساخت ریپازیتوری

1. یک ریپازیتوری **جدید و خصوصی (Private)** در GitHub بسازید، مثلاً
   `nobitex-executor`.
2. تمام فایل‌های این پروژه را در آن قرار دهید (`executor.py`,
   `nobitex_client.py`, `signal_parser.py`, `state_store.py`,
   `requirements.txt`, `.github/workflows/run.yml`, `.gitignore`).

## ۲) ساخت یک ربات تلگرام تازه (فقط برای خواندن)

1. در تلگرام به `@BotFather` پیام دهید و `/newbot` بزنید. یک توکن جدید
   می‌گیرید (چیزی شبیه `123456:ABC-...`).
2. این ربات تازه را به همان کانال مشترک اضافه کنید و **ادمین** کنید (بدون
   ادمین بودن، ربات پیام‌های کانال را از طریق API دریافت نمی‌کند). لازم
   نیست اجازه‌ی ارسال پیام بدهید، فقط عضویت/ادمین بودن کافی است.
3. برای پیدا کردن `chat_id` عددی کانال: یکی از پیام‌های کانال را به
   `@getidsbot` (یا مشابه) فوروارد کنید تا عددی شبیه `-1001234567890`
   بدهد.
4. برای هشدارهای ادمین (پیام‌های پارس‌نشده، خطاها): با `@userinfobot`
   `chat_id` شخصیِ خودتان را در تلگرام پیدا کنید و به ربات تازه یک پیام
   بدهید (Start) تا بتواند برایتان پیام بفرستد.

## ۳) ساخت API Key نوبیتکس (روی testnet شروع کنید)

1. وارد حساب نوبیتکس (یا حساب تست‌نت، طبق آنچه خودشان مشخص کرده‌اند) شوید.
2. به بخش «کلید API» بروید و یک کلید جدید بسازید با:
   - `permissions: READ,TRADE`
   - `ipAddressesWhitelist`: **خالی بگذارید** — چون سرورهای GitHub Actions
     IP ثابت ندارند. (این یعنی کلید بدون محدودیت IP کار می‌کند؛ برای همین
     حتماً `TRADE` را جدا از `WITHDRAW` نگه دارید تا حتی در بدترین حالتِ
     افشای کلید، امکان برداشت وجه وجود نداشته باشد.)
   - کد دوعاملی (`X-TOTP`) را طبق دستور سایت وارد کنید.
3. مقدار `privateKey` فقط همین یک‌بار نمایش داده می‌شود — همان لحظه در جای
   امن (نه در چت، نه در ریپازیتوری) کپی کنید.
4. مقدار `key` (کلید عمومی) را هم نگه دارید.

## ۴) تنظیم Secrets در GitHub

در ریپازیتوری: Settings → Secrets and variables → Actions → New repository secret

| نام Secret | مقدار |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن ربات مرحله‌ی ۲ |
| `TELEGRAM_CHANNEL_ID` | مثلاً `-1001234567890` |
| `TELEGRAM_ADMIN_CHAT_ID` | chat_id شخصی شما برای هشدارها |
| `NOBITEX_PUBLIC_KEY` | فیلد `key` |
| `NOBITEX_PRIVATE_KEY` | مقدار `privateKey` |
| `NOBITEX_BASE_URL` | `https://testnetapiv2.nobitex.ir` (اول تست، بعداً عوض کنید) |
| `RISK_MARGIN_USDT` | `1` |
| `LEVERAGE` | `10` |

## ۵) اجرا

1. به تب Actions بروید، workflow با نام `nobitex-executor` را پیدا کنید و
   دستی (`Run workflow`) اجرا کنید تا مطمئن شوید کار می‌کند.
2. لاگ‌ها را نگاه کنید — هر پیامی که پارس نشود همان‌جا با هشدار مشخص
   می‌شود.
3. بعد از این، خودش طبق زمان‌بندی (هر ~۵ ساعت و ۲۰ دقیقه، پیوسته در طول آن
   بازه) اجرا می‌شود.

## ۶) قبل از رفتن روی حساب واقعی — این‌ها را حتماً چک کنید

این‌ها فرض‌هایی هستند که در نبود نمونه‌ی واقعی پیام کانال گذاشته شده‌اند و
**باید با چند پیام واقعی تایید/اصلاح شوند**:

1. **فرمت دقیق نماد در پیام‌ها** (`symbol_to_currencies` در `executor.py`):
   فرض شده پیام‌ها چیزی شبیه `BTC` یا `BTCUSDT` می‌فرستند. اگر فرمت واقعی
   فرق دارد (مثلاً `BTC/USDT`)، این تابع باید اصلاح شود.
2. **دقت اعشار مقدار سفارش**: هر بازار در نوبیتکس احتمالاً حداقل/حداکثر
   حجم و تعداد رقم اعشار مجاز خودش را دارد (از `margin/markets/list`
   قابل استخراج است). فعلاً کد همیشه ۸ رقم اعشار می‌فرستد که ممکن است برای
   برخی بازارها رد شود — بعد از چند تست روی testnet این را دقیق کنید.
3. **زمان‌بندی سقف ۳۰ روزه‌ی پوزیشن** که در مستندات نوبیتکس آمده -
   فعلاً هیچ هشداری برایش در کد گذاشته نشده؛ اگر تایم‌فریم‌های بالا دارید
   بهتر است اضافه شود.
4. با مبلغ بسیار کوچک واقعی شروع کنید، نه مستقیم با اندازه‌ی کامل.

## ساختار فایل‌ها

- `nobitex_client.py` — امضای Ed25519 و فراخوانی API نوبیتکس (باز/بستن
  پوزیشن، لیست پوزیشن‌ها)
- `signal_parser.py` — تشخیص نوع پیام کانال از روی متن آن
- `state_store.py` — ذخیره‌ی وضعیت در `state.json`
- `executor.py` — حلقه‌ی اصلی: خواندن تلگرام → پارس → اجرا روی نوبیتکس
- `.github/workflows/run.yml` — اجرای رایگان و مستمر روی GitHub Actions
